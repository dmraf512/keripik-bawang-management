# Keripik Bawang — Business Management System

Aplikasi manajemen usaha keripik bawang berbasis React, TypeScript, dan Supabase.

## Run Locally

Prerequisites: Node.js

1. Install dependencies:
   npm install

2. Configure environment variables in `.env.local`:
   - VITE_SUPABASE_URL
   - VITE_SUPABASE_PUBLISHABLE_KEY

3. Run the application:
   npm run dev

## Technology Stack

- React
- TypeScript
- Vite
- Supabase PostgreSQL
- Supabase Authentication
- Recharts
